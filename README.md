# DIO Studies

## Sobre o repositório

Este repositório é dedicado aos estudos, exercícios práticos, desafios de código e projetos desenvolvidos durante os cursos, formações e bootcamps da plataforma Digital Innovation One (DIO).

Seu propósito é documentar minha jornada de aprendizado, consolidar conhecimentos técnicos e acompanhar minha evolução em programação, desenvolvimento backend, banco de dados e engenharia de software.

Além da conclusão dos cursos e obtenção de certificações, o objetivo é desenvolver autonomia técnica, capacidade de resolução de problemas e compreensão dos conceitos aplicados em situações reais.

## Objetivos

- Consolidar os fundamentos de programação.
- Desenvolver conhecimentos em Python e SQL.
- Aplicar os princípios da programação orientada a objetos.
- Desenvolver e integrar APIs REST.
- Modelar e gerenciar bancos de dados relacionais.
- Aplicar boas práticas de programação e engenharia de software.
- Desenvolver códigos legíveis, reutilizáveis e testáveis.
- Aprimorar a capacidade de resolução de problemas.
- Documentar conhecimentos adquiridos e a evolução dos projetos.
- Obter certificações relevantes para o desenvolvimento profissional.

## Organização do repositório

O repositório é organizado por áreas de conhecimento, em vez de formações ou bootcamps específicos.

Essa abordagem permite consolidar conteúdos apresentados em diferentes cursos, evitar duplicações e acompanhar a evolução dos conhecimentos e projetos ao longo do tempo.

| Diretório   | Descrição                                    |
| ----------- | -------------------------------------------- |
| `projects/` | Projetos práticos e suas respectivas versões |

A estrutura será ampliada progressivamente conforme novos conteúdos forem estudados.

## Metodologia de aprendizado

Os estudos realizados neste repositório seguem uma abordagem teórica e prática, buscando transformar os conhecimentos adquiridos em competências técnicas.

O processo de aprendizado contempla:

1. Estudo dos conceitos teóricos.
2. Análise de exemplos e implementações.
3. Resolução de exercícios práticos.
4. Desenvolvimento de soluções.
5. Revisão e correção do código.
6. Refatoração e aplicação de melhorias.
7. Documentação dos conhecimentos adquiridos.

O objetivo não é apenas reproduzir soluções apresentadas durante os cursos, mas compreender, adaptar e implementar os conceitos de maneira independente.

## Evolução dos projetos

Alguns projetos são desenvolvidos de maneira incremental ao longo de diferentes cursos e formações.

Sempre que relevante, as versões anteriores serão preservadas para demonstrar a evolução das implementações, as melhorias arquiteturais e a aplicação de novos conhecimentos.

Cada projeto poderá possuir sua própria documentação, contendo:

- Descrição e objetivos.
- Requisitos funcionais.
- Regras de negócio.
- Tecnologias utilizadas.
- Estrutura de arquivos.
- Instruções de execução.
- Testes e validações.
- Histórico de versões.
- Melhorias futuras.
- Referências utilizadas.

As informações específicas estarão disponíveis no README de cada projeto.
